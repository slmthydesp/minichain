# Chain id、gas、回执与替换 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 签名覆盖 chain id `6666`，转账支付 gas 给 coinbase，区块承诺回执根，更高 gas 单价替换同 nonce 交易。

**Architecture:** 交易字节一次扩成 60 字节签名原文。`Apply` 返回实际 gas。`Mine` 按区块 gas 上限挑选，并把费用打进 coinbase。回执根进入区块哈希。交易池在同 nonce 上按单价替换。

**Tech Stack:** Go 1.26.1，现有 `golang.org/x/crypto/sha3` 与 `secp256k1`。不新增依赖。

**Spec:** `docs/superpowers/specs/2026-10-30-fees-design.md`

## Global Constraints

- Chain id 常量 `6666`。只接受这个值。错误文本 `wrong chain id`。
- `IntrinsicGas` 是 `21000`。`BlockGasLimit` 是 `100000`。
- 签名原文 60 字节：`to(20) + value + nonce + gasLimit + gasPrice + chainId`，后五项各 `uint64` 大端。规范交易 125 字节。20 加五个 8 字节等于 60，不要再补 8 个零。
- 实际收费是 `21000 * gasPrice`。池按 `gasLimit * gasPrice + value` 预留。
- 空回执根是 `c5d2460186f7233c927e7db2dcc703c0e500b653ca82273b7bfad8045d85a470`。
- 不新增依赖。测试不调用 `time.Sleep`。`gofmt` 改过的 Go 文件。
- 不要提交这些已暂存、但不属于本计划的路径：`view/`、`cmd/view/`、`docs/superpowers/plans/2026-10-30-view.md`、`docs/superpowers/specs/2026-10-30-view-design.md`、`docs/superpowers/specs/2026-10-30-forks-design.md`。改 README 时保留「看链」那一节。
- 提交只用 `git commit --only -- <本任务文件>`，提交说明是 `<package>: 小写描述`。
- 工作目录是仓库根。每个任务结束时 `go test ./...` 通过。
