# minichain

这是一条只放在内存里的链，用来看清出块、分叉和同步。进程退出后链就没了。没有节点发现，也没有数据库。

开两个进程时，各自都会出块，也会向对方拉已经封好的块。同一父块上可以长出两块，这就是一次分叉。节点把分叉都留着，再选出一条来当链头：高度更大的优先；高度相同，则区块哈希字节更小的优先。换链头时，被丢掉那条分叉上的交易会回到本机交易池。两边选出同一条链之后，状态根相同。

链头往前数 12 块是已经定下来的。从这 12 块之前分出去的叉，即使更长，也不会再被选成链头。

账户可以只有余额，也可以带上代码和存储。收款方没有代码时，这笔交易就是转账。有代码时，按操作码执行。没有 data 的转账，起步 gas 是 21000。1 个币等于 10^18 个最小单位，金额按最小单位填写。

原理说明见 `LEARNING_GUIDE.md`。还没做的部分见 `TODO.md`。

## 启动两个进程

两个进程都要写上对方的地址，并且用不同的 `--coinbase`。区块哈希里含有 coinbase、父块、交易和时间。这些都一样时，两边挖出的是同一块，看不到分叉。

先开终端 1，监听 `127.0.0.1:8545`。启动后标准错误会打印实际的监听地址、coinbase、出块间隔、chain id 和 peer。终端 2 还没起来时会打印一次 `sync:`，之后同样的失败不再重复打，这个进程继续出块。对方一旦应答，会打印一次 `sync: connected` 和对方地址：

```bash
go run ./cmd/node \
  --listen 127.0.0.1:8545 \
  --peers http://127.0.0.1:8546 \
  --coinbase 0xf39fd6e51aad88f6f4ce6ab8827279cfffb92266
```

再开终端 2，监听 `127.0.0.1:8546`：

```bash
go run ./cmd/node \
  --listen 127.0.0.1:8546 \
  --peers http://127.0.0.1:8545 \
  --coinbase 0xCfEAe9d951107B18c3495247D8249AD005175707
```

两个进程还没选中同一条链时，先别发交易。收到交易的进程只看自己账本里这个账户的余额和 nonce：余额不够，或者 nonce 已经用过，就拒绝。两边账本不一样时，同一笔交易可能一个进程收下，另一个拒绝。

```bash
curl -s http://127.0.0.1:8545/status | jq .
curl -s http://127.0.0.1:8546/status | jq .
```

两边的 `height` 和 `stateRoot` 相同之后再发交易。刚分叉时这两个值会不同。分叉点还在最近 12 块以内时，下一轮同步后会再次相同。分叉点已经早于这 12 块时，这次同步不会把链头换过去。

## 发一笔交易

演示私钥是 `ac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80`，地址是 `0xf39fd6e51aad88f6f4ce6ab8827279cfffb92266`。创世时这个账户有 `1000000000000000000`，也就是 1 个币。`--key` 不写就用这把钥匙。

`--value` 填最小单位。下面例子里的 `10` 是 10 个最小单位，不是 10 个币。`--to` 留空是创建合约，`--data` 是调用数据或初始代码。`--gas-limit` 默认 `21000`，`--gas-price` 默认 `1`。chain id 固定为 `6666`。

`--nonce` 可以不写。不写时，`cmd/send` 向 `--url` 那个进程查询下一笔 nonce，并把它打到标准错误。查的是链上已经入块的 nonce，再跳过这个进程交易池里已经占住的号码；池里有缺口时先填缺口。写了 `--nonce` 就用你给的数。查看页订阅到的 `nonce` 仍是已经入块的值。

发给任一进程。本机收下就返回 `204`，并把同一份 JSON 转给 `--peers`。对方拒绝或连不上，本机仍保留这笔交易。

```bash
go run ./cmd/send \
  --url http://127.0.0.1:8545 \
  --to 0x0000000000000000000000000000000000000001 \
  --value 10
```

再发这个账户的下一笔。上一笔还在这个进程的交易池里时，查到的 nonce 是 `1`：

```bash
go run ./cmd/send \
  --url http://127.0.0.1:8546 \
  --to 0x0000000000000000000000000000000000000001 \
  --value 5
```

等下一个出块间隔（默认 5 秒），再看两个 status。两边的 `height` 和 `stateRoot` 会相同。

## 关掉一边

在任一终端按 Ctrl-C。另一边继续出块。它连不上对方时，标准错误打印一次 `sync:`，进程不退出。再次连上会再打印一次 `sync: connected`。

## 看链

先按上面的方式启动出块进程，再开一个查看进程。启动后标准错误会打印实际的监听地址：

```bash
go run ./cmd/view
```

浏览器打开 `http://127.0.0.1:8080`，填入出块进程的地址，例如 `127.0.0.1:8545` 或 `http://127.0.0.1:8546`。带 `http://` 或 `https://` 时，页面会去掉协议，仍按 `主机:端口` 去连。每一列是该进程当前的链头，以及从链头往回能看见的块。最新的块在上面。

余额一节可以再填同一个进程地址和一个账户地址，订阅这个进程上的余额和 nonce。可以同时订多个。页面每 3 秒向该进程查一次。金额按最小单位显示，并换算成币。

页首的「暂停监控」同时停下链和余额的刷新，画面停在点下去的那一刻。再点「继续监控」，旧数据清掉，按当时的链重新拉。
