# minichain

两个进程各出各的块，也互相拉块。同一父块上可以出现两块。节点留下这些分叉，高度更大的成为链头；高度相同则哈希更小的成为链头。换链头时，被放弃的交易回到本机交易池。两边最后对规范链算出同一个状态根。

没有 EVM、合约、gas、节点发现和数据库。链只在内存里。

## 测试

```bash
go test ./...
```

## 启动

两个进程要互相写上对方的地址，并且用不同的 `--coinbase`。coinbase 相同、父块相同、交易也相同的块是同一块，看不到分叉。

终端 1，监听 `127.0.0.1:8545`。对方还没起来时，标准错误会打印 `sync:`，进程继续出块：

```bash
go run ./cmd/node \
  --listen 127.0.0.1:8545 \
  --peers http://127.0.0.1:8546 \
  --coinbase 0xf39fd6e51aad88f6f4ce6ab8827279cfffb92266
```

终端 2，监听 `127.0.0.1:8546`：

```bash
go run ./cmd/node \
  --listen 127.0.0.1:8546 \
  --peers http://127.0.0.1:8545 \
  --coinbase 0x0000000000000000000000000000000000000002
```

先等两边高度一致，再发交易。收到交易的进程用本机状态检查 nonce 和余额。

```bash
curl -s http://127.0.0.1:8545/status
curl -s http://127.0.0.1:8546/status
```

两边的 `height` 和 `stateRoot` 相同之后再继续。分叉刚发生时它们会不同，下一轮同步后再次相同。

## 发一笔转账

演示私钥是 `ac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80`，地址是 `0xf39fd6e51aad88f6f4ce6ab8827279cfffb92266`，创世余额 `1000000`。`--key` 不写就用这把钥匙。

发给任一进程。本机收下就返回 `204`，并把同一份 JSON 转给 `--peers`。对方拒绝或连不上，本机仍保留这笔交易。

```bash
go run ./cmd/send \
  --url http://127.0.0.1:8545 \
  --to 0x0000000000000000000000000000000000000001 \
  --value 10 \
  --nonce 0
```

再发一笔：

```bash
go run ./cmd/send \
  --url http://127.0.0.1:8546 \
  --to 0x0000000000000000000000000000000000000001 \
  --value 5 \
  --nonce 1
```

等下一个出块间隔，然后再看两个 status。规范链上的 `stateRoot` 相同，`height` 相同。

## 一边关掉的时候

在任一终端按 Ctrl-C。另一边继续出块，标准错误继续打印 `sync:`，进程不退出。
